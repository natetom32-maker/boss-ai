<original_problem_statement>
The user wants to build an advanced AI application called Boss AI. It is not a chatbot, but an AI operating layer that remembers decisions, runs on autopilot by default, and only pauses at risk checkpoints (sending/spending/deleting/legal).

**PRODUCT REQUIREMENTS:**
- **Memory Engine:** A structured, event-sourced memory system with different levels (L0 Prime, L1 Workspace, L2 Project, L3 Session). State must be rebuildable from an append-only event log.
- **Autopilot Contract:** The AI should proceed automatically by default and only stop for critical checkpoints.
- **Memory Receipt UI:** A UI element that shows the user what memory was used and why.
- **Multi-model Routing:** The system should automatically choose the best AI model (GPT, Gemini, etc.) for a given task behind the scenes.
- **D-ID Integration:** A talking avatar (stylized statue) should serve as the visual presentation layer for the AI's responses. The avatar is a view layer and should be driven entirely by the Boss AI core logic.
- **Architecture:** A single, unified backend system where the D-ID avatar is a client that consumes the Boss AI APIs. There should be one source of truth for memory and state.
</original_problem_statement>
